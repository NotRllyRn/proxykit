# Repository guidance

- Read `docs/PROJECT_DIRECTION.md` before planning or implementing.
- The initial handoff is context ingestion only. Do not begin implementation until the user explicitly requests it in the new thread.
- Use generic labels such as "Personal usage", "Work laptop", and "Example user" in examples, fixtures, and UI. Do not publish personal conversation details, credentials, or private transcripts.
- Prefer small, reviewable changes, explicit contracts, minimalism, and tests of observable behavior. Avoid speculative frameworks.
- Distinguish proposed architecture, implemented behavior, and externally documented claims.
