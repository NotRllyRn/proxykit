# WeaveProxy

A customizable HTTP proxy core with modular extensions for routing, context management, gateway tools, and observability.

**Status: architecture brief only. No proxy implementation exists yet.**

Start with [Project direction and architecture](docs/PROJECT_DIRECTION.md). It captures the founding goals, research, proposed boundaries, and questions to resolve before implementation.

The project takes inspiration from Codex Broker, Pi's extension authoring experience, and context gateways. It is not a Pi compatibility layer or a claim of universal client support.
